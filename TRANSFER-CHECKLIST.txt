=======================================

Development target: v0.06-alpha Build #1 (unreleased working state)

INCLUDED
--------
- Complete current repository worktree, including tracked and untracked source.
- .git metadata, local history, branches, index, and current worktree status.

- Generated bin, obj, native out/build, temporary publish, and artifact directories.
- Personal browser profiles, cookies, provider logins, DRM/provider state, Nord DPAPI

MACHINE-BOUND STATE
-------------------
Nord credentials protected with Windows DPAPI may need to be entered again. Provider/browser
sign-ins and DRM state may not transfer safely between Windows PCs. Do not weaken those
protections; use a clean adjacent Data folder and sign in again where necessary.

FIRST CHECKS ON THE MAIN PC
---------------------------
From the extracted repository root, run:

  git status --short
  dotnet --info
  dotnet restore .\MonkeyTV\MonkeyTV.csproj
  dotnet build .\MonkeyTV\MonkeyTV.csproj -c Release --no-restore
  dotnet run --project .\tests\MonkeyTV.SmokeTests\MonkeyTV.SmokeTests.csproj -c Release

Also verify:

  Runtime\WebView2Fixed\msedgewebview2.exe
  Runtime\VpnV2\MonkeyTV.UserSpaceOpenVpnProof.exe
  Runtime\VpnV2\libcrypto-3-x64.dll
  Runtime\VpnV2\libssl-3-x64.dll
  Runtime\VpnV2\lz4.dll

Normal Monkey TV development requires Windows 11 x64, Git, the .NET 8 SDK, and NuGet access.
Only native-helper rebuilding additionally requires MSVC x64 Build Tools, CMake 3.25+, Ninja,
and a bootstrapped vcpkg checkout configured as described in
native\MonkeyTV.UserSpaceOpenVpnHelper\README.md.
